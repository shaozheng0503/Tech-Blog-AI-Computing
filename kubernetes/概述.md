# Kubernetes (K8s) 概述

## 🚀 什么是 Kubernetes

**Kubernetes（K8s）**是一个开源的容器编排平台，用于自动化部署、扩展和管理容器化应用程序。它消除了在部署和扩展容器化应用时涉及的许多手动操作，使得应用程序的管理更加高效和便捷。

### 核心特性

- **自动化部署和扩展**：自动部署容器化应用，根据需求自动扩展或收缩
- **自我修复**：自动替换失败的容器，确保应用的高可用性
- **负载均衡**：自动分发网络流量，确保应用稳定运行
- **存储编排**：自动挂载存储系统，支持本地存储、云存储等
- **密钥和配置管理**：安全地部署和更新密钥和配置，无需重建容器镜像

### 历史背景

Kubernetes 起源于谷歌的 Borg 系统，2014年首次发布，旨在为开发者提供一个强大的容器管理解决方案。经过多年发展，已成为云原生应用的事实标准。

### 核心组件

#### Master 节点组件

1. **API Server**
   - 集群的统一入口，提供 REST API 接口
   - 负责组件间的通信和认证授权
   - 支持水平扩展，提高可用性

2. **etcd**
   - 分布式键值存储系统
   - 存储集群的所有配置信息和状态
   - 支持高可用部署

3. **Scheduler**
   - 负责 Pod 的调度决策
   - 根据资源需求、亲和性规则等选择最佳节点
   - 支持自定义调度策略

4. **Controller Manager**
   - 维护集群状态，确保期望状态与实际状态一致
   - 包含多种控制器：ReplicaSet、Deployment、Service 等
   - 自动修复和扩缩容

#### Worker 节点组件

1. **kubelet**
   - 节点代理，管理本节点的 Pod 生命周期
   - 执行 Pod 的创建、修改、删除等操作
   - 定期向 API Server 报告节点状态

2. **kube-proxy**
   - 网络代理，实现 Service 的网络规则
   - 支持多种网络模式：iptables、IPVS 等
   - 负责负载均衡和服务发现

3. **Container Runtime**
   - 容器运行时，如 Docker、containerd、CRI-O
   - 负责容器的创建、运行、销毁等操作
   - 支持 OCI 标准

## 🔧 核心概念

### 1. Pod

Pod 是 Kubernetes 中最小的可部署单元，包含一个或多个容器。

```yaml
apiVersion: v1
kind: Pod
metadata:
  name: nginx-pod
  labels:
    app: nginx
spec:
  containers:
  - name: nginx
    image: nginx:latest
    ports:
    - containerPort: 80
```

**特点：**
- 共享网络命名空间
- 共享存储卷
- 生命周期管理
- 资源限制和请求

### 2. Service

Service 为 Pod 提供稳定的网络端点，实现负载均衡和服务发现。

```yaml
apiVersion: v1
kind: Service
metadata:
  name: nginx-service
spec:
  selector:
    app: nginx
  ports:
  - port: 80
    targetPort: 80
  type: ClusterIP
```

**类型：**
- **ClusterIP**：集群内部访问
- **NodePort**：通过节点端口访问
- **LoadBalancer**：云平台负载均衡器
- **ExternalName**：外部服务别名

### 3. Deployment

Deployment 管理 Pod 的副本，支持滚动更新和回滚。

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: nginx-deployment
spec:
  replicas: 3
  selector:
    matchLabels:
      app: nginx
  template:
    metadata:
      labels:
        app: nginx
    spec:
      containers:
      - name: nginx
        image: nginx:1.19
```

**特性：**
- 自动扩缩容
- 滚动更新策略
- 健康检查
- 版本回滚

### 4. ConfigMap 和 Secret

**ConfigMap**：存储非敏感配置数据
```yaml
apiVersion: v1
kind: ConfigMap
metadata:
  name: app-config
data:
  database_url: "mysql://localhost:3306/app"
  log_level: "INFO"
```

**Secret**：存储敏感信息
```yaml
apiVersion: v1
kind: Secret
metadata:
  name: db-secret
type: Opaque
data:
  username: YWRtaW4=  # base64 encoded
  password: cGFzc3dvcmQ=  # base64 encoded
```

## 🚀 实际应用场景

### 1. 微服务架构

Kubernetes 是微服务架构的理想平台：

- **服务发现**：自动注册和发现服务
- **负载均衡**：智能分发请求
- **配置管理**：集中化配置和密钥管理
- **监控日志**：集成监控和日志收集

### 2. 持续部署 (CI/CD)

```yaml
# 示例：GitLab CI 部署到 Kubernetes
deploy:
  stage: deploy
  script:
    - kubectl apply -f k8s/
    - kubectl rollout status deployment/app
  environment:
    name: production
```

### 3. 大数据和机器学习

- **弹性计算**：根据任务需求自动扩缩容
- **GPU 管理**：支持 GPU 资源调度
- **批处理作业**：Job 和 CronJob 资源
- **存储管理**：支持各种存储后端

### 4. 边缘计算

- **多集群管理**：Karmada、KubeFed 等
- **轻量级部署**：K3s、MicroK8s
- **边缘节点管理**：支持边缘设备部署
